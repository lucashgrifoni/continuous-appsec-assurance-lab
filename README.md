# continuous-appsec-assurance-lab

Experimental laboratory. **Synthetic content only.**

This repository exists only to observe how GitHub records the chain pull request → workflow run → job → check run → ruleset → rule suite for a trivial workflow. It contains no application, no scanner, no dependencies and no code of the Continuous AppSec Assurance product.

Nothing here comes from any employer or client. Results observed here are functional observations in a public repository and do not establish permission boundaries.
